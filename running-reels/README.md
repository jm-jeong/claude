# 러닝 3요소 릴스 1·2·3편

Claude Design 캔버스에서 가져온 원본 슬라이드와 강의 자료 작업 폴더입니다.

- 원본 캔버스: https://claude.ai/artifact/58tgpYbPt69apMZRM38KAM
- `design/` — 슬라이드 원본(`.dc.html`, 1080×1920)과 `canvas.json`(순서와 제목). 폰트와 이미지는 캔버스 안에 저장돼 있어서, 이 파일만으로는 화면이 그대로 렌더링되지 않습니다.
- `slides-outline.md` — 슬라이드별 텍스트를 자동으로 뽑은 개요. 강의안과 대본 작업의 기준으로 씁니다.

- `e3r-script.md` — 3편 재구성안 32장 대본. 화면에서 뺀 숫자·조건·해석과 출처를 장별로 정리.
- `e4-research.md` — 4편(젖산역치) 주장별 근거 수준, 상식 검증, 엘리트 훈련 메모, 뺀 주장.

- `e5-research.md` — 5편(고지대 트레이닝) 주장별 근거 수준, 훈련지 고도, 상식 검증, 확인 못 한 항목.
- `e5-script.md` — 5편 장별 말하기 대본 (화면 문구 · 말로 할 설명 · 출처).
- `e6-research.md` — 6편(플라이오메트릭) 주장별 근거 수준, 연구 용량, 상식 검증, 엘리트 현장 사례, 확인 못 한 항목.
- `e6-script.md` — 6편 장별 말하기 대본 (화면 문구 · 말로 할 설명 · 출처). 2차 자료 숫자는 대본에만 표시.
