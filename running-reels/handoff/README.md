## 올리는 법

- 한 편만 작업할 때: 그 편의 `md`와 `pdf` 두 개를 같이 올리세요.
- 전부 넘길 때: 10개 파일을 한 번에 올려도 돼요. 채팅 한 번에 파일 약 20개, 파일당 30MB까지 올릴 수 있고, PDF는 100쪽 이하가 잘 읽혀요. 여기 PDF는 모두 35쪽 이하, 6MB 이하예요.
- zip(`러닝기록분석-3~7편.zip`)은 보관용이에요. 채팅에는 zip을 풀어서 파일로 올리는 게 확실해요.
- PDF 쪽마다 "NN장 · 이름"이 적혀 있어서, 채팅에서 "4편 13장 고쳐줘"처럼 말하면 돼요.

## 첫 메시지 예시

> 러닝 기록 분석 시리즈 자료야. md에 장별 말하기 대본과 출처가 있고, pdf가 슬라이드야. 원칙(근거 수준 표시, 상관을 원인처럼 말하지 않기)을 지키면서 같이 작업하자.
