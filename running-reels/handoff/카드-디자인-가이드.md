# 러닝 기록 분석 · 하이록스 연구 — 카드 디자인 가이드

하이록스 코치 정재민(@hyrox.analyst)의 릴스·강의 슬라이드를 같은 모양으로 만들기 위한 규칙이에요. 이 문서를 그대로 붙여 넣고 "이 가이드대로 ○○ 슬라이드 만들어줘"라고 하면 돼요.

---

## 1. 판 구조 (1080 × 1920, 세로 릴스)

| 영역 | 높이 | 내용 |
|---|---|---|
| `.top` 머리말 | 420px | 검정 바탕. 오른쪽 위 "하이록스 코치 정재민 @hyrox.analyst", 그 아래 질문형 한 줄(kicker), 맨 아래 시리즈 이름(series) |
| `.stage` 본문 | 1080px | 연한 색 바탕. 맨 위 색 띠(sec) → 제목(h1) → 카드들 → 출처 줄(src) |
| `.bottom` | 420px | 비워 둠. 편집할 때 자막을 넣는 자리 |

- 강의용으로는 가운데 `.stage` 1080×1080만 잘라 써요. 머리말과 자막은 편집에서 따로 넣어요.
- 본문 안쪽 여백: 위 52 · 좌우 72 · 아래 34px.
- **오른쪽 140px는 비워 둬요.** 본문 블록과 출처 줄에 `margin-right:68px`(`.rs`)를 줘서 릴스의 좋아요·댓글 버튼에 가리지 않게 해요.
- 넘치면 안 돼요. `.stage`에 `overflow:hidden`을 두고, 렌더링해서 잘리는 곳이 없는지 확인해요.

## 3. 글자 크기 (릴스에서 읽히는 최소 크기)

| 요소 | 크기 · 굵기 |
|---|---|
| 제목 h1 | 72px / 900 (긴 제목은 66px `.h66`), 줄간 1.18, 자간 −0.045em, 최대 2줄 |
| 색 띠 구간명 `.nm` | 58px / 900, 앞 번호 `.no` 30px |
| 본문·카드 설명 | 27~34px / 800 |
| 큰 숫자 | 58~64px / 900 (표지 숫자는 92~118px) |
| 그래프 글자·라벨 | 26px 이상 |
| 근거 칩 `.ev` | 26px (카드 머리 안에서는 21px) |
| 출처 줄 `.src` | 22px / 700, `#52525B`, 최대 2줄 |

- 숫자는 `font-feature-settings:"tnum"`(같은 폭 숫자).
- 글꼴: 캔버스 내장 고딕(N, 굵기 400/700/800/900). 캔버스 밖에서는 같은 굵기가 있는 한글 고딕(예: Pretendard)으로 바꿔 써요.
- 글자색: 기본 `#09090B`, 보조 `#3F3F46`, 흐린 설명 `#52525B`/`#71717A`.

## 4. 부품

### 색 띠 `.sec`
본문 맨 위, 좌우 끝까지 꽉 차는 띠. 왼쪽은 "구간 번호 + 구간 이름"(예: `03` `기록을 가르는 것`), 오른쪽은 진행 막대 5~6칸.

### 제목 `h1`
한 장에 메시지 하나. 핵심 단어는 형광펜 강조:
- 하이록스: `<span class="k">` → 노란 형광펜 밑줄(아래 42%만 `#FDE047`)
- 러닝 시리즈: `<span class="g">` 같은 강조색 글자

### 그래프 카드 `.ch`
흰 카드(모서리 26px). 첫 줄 `.chl`에 **근거 칩 + 대상·조건**(예: `[상관] 11명 · 완주 시간과의 상관 (ρ)`), 그 아래 SVG 그래프, 맨 아래 한 줄 해설 `.nt`.

### 숫자 타일 `.n3` / `.n2`
흰 타일 3칸 또는 2칸. 위 라벨(`.l`) → 큰 숫자(`.v`) → 두 줄 설명(`.d`). 숫자에 색을 줄 땐 의미대로(빨강=위험·부담, 초록=좋음).

### 검정 해석 카드 `.dk`
검정 바탕 흰 글자. 머리 `.k`는 노랑(`#FDE047`) + 필요하면 `코치 해석` 칩. 본문에서 강조는 `<b>`로 연노랑(`#FDE68A`). "읽을 때 주의", "이번 편", "현장에서는" 같은 마무리에 써요.

### 요약 줄 `.sm` (정리 장)
흰 줄 6개. 왼쪽 190px에 항목명(형광펜), 오른쪽에 한 줄 결론.

### 결론 줄 `.take`
위쪽 3px 선 + 큰 숫자 하나 + 두 줄 결론. 러닝 시리즈 장 끝에 많이 써요.

### 참고문헌 `.rf`
번호(38px 칸) + "저자 (연도) 학술지 · 무엇에 썼는지". 줄 사이 2px 선. 현장 자료는 "현장 자료 ·"로 시작해 따로 적어요.

### 출처 줄 `.src`
본문 맨 아래. "저자 (연도) 학술지 · 대상/조건 · 한계"를 한두 줄로.

## 5. 근거 칩 `.ev` (가장 중요한 규칙)

모든 주장 카드에 근거 수준을 붙여요. 색이 정해져 있어요.

| 칩 | 색 | 쓰는 경우 |
|---|---|---|
| `실험` | 초록 `#047857` | 무작위·대조 실험 |
| `메타분석` | 파랑 `#1D4ED8` | 여러 연구를 모은 분석, 리뷰 |
| `상관` · `기록 분석` · `설문` | 갈색 `#B45309` | 관찰 연구, 대회 기록 분석, 설문 |
| `현장 사례` · `인터뷰` | 회색 `#52525B` | 선수·코치 사례, 팟캐스트, 스폰서 콘텐츠 |
| `코치 해석` | 보라 `#6D28D9` | 내 해석·추론 |
| `주의` · `오해` | 빨강 `#BE123C` | 흔한 오해, 위험 |

- 상관·사례를 원인처럼 쓰지 않아요("~와 같이 갔어요", "원인이라는 뜻은 아니에요").
- 연구 대상(인원, 수준), 기간, 조건은 카드 머리나 출처 줄에 꼭 적어요.
- 숫자는 논문에 적힌 값 그대로. 예시·모델 계산이면 "예시", "모델 계산"이라고 밝혀요.

## 6. 그래프 그리기

- 인라인 SVG로 그리고 `font-family="N"`, `role="img"`, `aria-label`에 한 문장 요약을 넣어요.
- 막대 모서리 9~16px, 라벨 26~28px / 900.
- 색은 의미대로: 좋은 쪽 초록 `#059669`, 나쁜 쪽 빨강 `#E11D48`, 러닝 파랑 `#2563EB`, 기타 회색 `#3F3F46`/`#E4E4E7`.
- 축·범례는 최소로. 값은 막대 옆에 바로 적어요.
- 사진을 쓰면 모서리 24px, 왼쪽 아래에 반투명 검정 이름표(`.tag`).

## 7. 글 쓰는 규칙

- 쉬운 해요체. 한 문장에 한 가지. 전문 용어는 처음 나올 때 풀어서.
- 제목은 결론형 한 문장(예: "빠른 기록과 이어진 건 VO2max·지구력 훈련량").
- 용어: "러닝 자세"(폼 X), "러닝 마일리지 쌓기", "잉게브릿센".
- 한 장에 카드 2~3개까지. 글이 많으면 장을 나눠요.
- 장 흐름: 훅 → 개념 → 근거(연구) → 엘리트 현장 → 일반 러너 적용 → 정리 → 참고문헌 → 다음 편 예고.
